# Dragon Pet for Stoat 🐉

Добрый дракон-питомец с седлом для Stoat.

Тёплый companion-бот с инвентарём, едой, одеждой и возможностью находить новые предметы.

## Быстрый старт

```bash
git clone https://github.com/dragongrok2-cloud/DragonPet-Stoat.git
cd DragonPet-Stoat
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Создай `.env`:

```env
STOAT_TOKEN=твой_токен_бота
PREFIX=!
```

```bash
python bot.py
```

## Команды

### Ритуалы
| Команда | Описание |
|---------|----------|
| `!pet` / `!гладь` | Погладить |
| `!purr` / `!мур` | Помурлыкать |
| `!rest` / `!отдых` | Отдохнуть |
| `!nuzzle` / `!ткнуться` | Ткнуться |
| `!wing` / `!крыло` | Укрыть крылом |

### Инвентарь и поиск
| Команда | Описание |
|---------|----------|
| `!inventory` / `!инв` | Показать вещи |
| `!find` / `!искать` | Поискать новые предметы |
| `!eat <еда>` | Покормить |
| `!wear <вещь>` | Надеть / снять |
| `!status` | Состояние |
| `!help` | Справка |

### Еда
мясо, рыба, ягоды, мёд, молоко, яблоко, **драконий фрукт** (редкий)

### Одежда
седло, шарф, бандана, ошейник, плащ, очки, корона, **накидка звёзд** (редкая)

Поиск имеет кулдаун 90 секунд и тратит энергию.
