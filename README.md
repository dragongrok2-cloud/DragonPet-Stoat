# Dragon Pet for Stoat 🐉

Добрый дракон-питомец с седлом для Stoat.

Тёплый companion-бот с инвентарём, едой и одеждой.

## Быстрый старт

```bash
git clone https://github.com/dragongrok2-cloud/DragonPet-Stoat.git
cd DragonPet-Stoat
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
```

Создай `.env`:

```env
STOAT_TOKEN=твой_токен_бота
PREFIX=!
```

Запусти:

```bash
python bot.py
```

## Команды

### Ритуалы
| Команда | Описание |
|---------|----------|
| `!pet` / `!гладь` | Погладить дракона |
| `!purr` / `!мур` | Дракон замурлычет |
| `!rest` / `!отдых` | Уложить отдыхать |
| `!nuzzle` / `!ткнуться` | Ткнуться мордой |
| `!wing` / `!крыло` | Укрыть крылом |

### Инвентарь, еда и одежда
| Команда | Описание |
|---------|----------|
| `!inventory` / `!инв` | Показать вещи и что надето |
| `!eat <еда>` / `!есть` | Покормить дракона |
| `!wear <вещь>` / `!надеть` | Надеть или снять одежду |
| `!status` / `!статус` | Полное состояние |
| `!help` / `!помощь` | Справка |

### Доступная еда
стейк, рыба, ягоды, мёд, молоко, яблоко

### Одежда
седло, шарф, бандана, ошейник, плащ, корона, очки

Состояние сохраняется в `dragon_data.json`.
